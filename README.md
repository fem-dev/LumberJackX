# LumberJackX

Automatic screen-based player for the **LumberJack Telegram Mini App** on Windows.

## اجرا در ویندوز

Python 3.11+ و Git باید نصب باشند. PowerShell را باز کن و فقط این دستورها را اجرا کن:

```powershell
git clone https://github.com/fem-dev/LumberJackX.git
cd LumberJackX
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py
```

قبل از اجرای برنامه، بازی را در Telegram Desktop باز کن و وارد حالت بازی شو. بعد از اجرای برنامه:

1. وقتی خواست، روی نقطه‌ای در سمت چپ و هم‌ارتفاع با سر بازیکن کلیک کن؛ نقطه باید جایی باشد که شاخه هنگام نزدیک‌شدن از آن عبور می‌کند.
2. همین کار را برای نقطه متناظر سمت راست انجام بده.
3. بعد از ثبت نقطه‌ها، موس خودکار به گوشه صفحه می‌رود و بات شروع به بازی می‌کند.

برای توقف بات کلید `Esc` را بزن. اگر بازی تمام شد، آن را دستی دوباره شروع کن؛ نقاط کالیبراسیون تا وقتی برنامه را نبندی حفظ می‌شوند.

نیازی به فایل EXE، OCR یا Tesseract نیست. برای دفعات بعد، داخل پوشه پروژه محیط را فعال کن و `python main.py` را اجرا کن؛ برای دریافت آخرین تغییرات، قبلش `git pull` بزن.

## روش تشخیص

- در شروع، دو نقطه ثابت از محل عبور شاخه‌ها کالیبره می‌شوند.
- در هر فریم، به‌جای حدس‌زدن رنگ لباس بازیکن یا پیدا کردن تنه، یک ناحیه کوچک اطراف نقطه سمت فعلی بررسی می‌شود.
- اگر سهم پیکسل‌های تیره در آن ناحیه از آستانه تعیین‌شده بیشتر باشد، جهت عوض می‌شود.
- فاصله پیش‌فرض حرکت‌ها `0.16` ثانیه است. آستانه‌ها و اندازه ناحیه در ابتدای `main.py` قابل تنظیم‌اند.

این روش از تشخیص رنگ کلی قبلی ساده‌تر و قابل‌کالیبره‌کردن‌تر است، اما هنوز باید با اندازه پنجره و ظاهر واقعی بازی آزمایش شود. اگر نقاط را اشتباه انتخاب کنی یا رنگ شاخه و پس‌زمینه متفاوت باشد، ممکن است نیاز به تنظیم آستانه‌ها باشد.

اگر PowerShell اجازه فعال‌سازی محیط را نداد، این دستور را در همان پنجره اجرا کن و سپس فعال‌سازی را دوباره انجام بده: `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass`.
